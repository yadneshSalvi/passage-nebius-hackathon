## Accepted decisions · 28 October 2026

- React/Vite and Fastify remain the product stack. SQLite WAL and content-addressed files replace the planned cloud database/object store for local delivery. No cloud resources were provisioned.
- Execution is limited to authored React interaction components in a trusted fixture host. Arbitrary repository import stays unavailable until disposable isolation exists. No model-selected host command or package script runs.
- Six variants cover four interaction families. Shared component ancestry is recorded and is not independent holdout evidence.
- A protected service persists real fictional bookings. The verifier uses keyboard input and exact stored-field comparisons independently of candidate source.
- Original/reference builds are separately compiled. Before/after is never a UI flag that changes expected results.
- Contract revisions are immutable. Changed requirements mark prior runs stale; retry creates a new explicit attempt.
- Live Nebius/NVIDIA generation and handcrafted reference mode are distinct. Deterministic tests do not call paid models; outages never silently substitute providers.
- Passage's Nebius admission budget is $2 within the user's initial four-project allowance. The later authorization enables uncapped paid development on explicitly selected Fireworks/Together routes. Provider ledgers remain separate; actual, reserved and unknown usage survive restart.
- Private text assistive captures are bound and revocable. Video/audio automation and actual participant studies remain unperformed.
